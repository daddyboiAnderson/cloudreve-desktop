# Cloudreve Desktop 0.2.1 — macOS

## Important: reconnect when upgrading from development builds

This release changes the macOS app identifier from `cloudreve.desktop.dev` to
`cloudreve.desktop` and its File Provider extension to
`cloudreve.desktop.fileprovider`. **Existing development-build users must
reconnect their Cloudreve drives.** This is a one-time identity transition, not
a requirement for subsequent updates using these production identifiers.

Before upgrading, save and close your documents, allow pending uploads to finish,
and separately back up any local files whose upload has not been confirmed.
Disconnect the old drives using the old app's Settings before replacing it.
Quit Cloudreve, install the new app in Applications, and reconnect in Settings.
Reapply your Keep Downloaded selections in the new Finder location. Old Finder
containers and local content are not automatically deleted by this release.
Do not run old and new builds simultaneously.

## Changes

- Transactional SQLite state and durable event delivery for macOS File Provider.
- Recovery of missed metadata events, including new nested folders.
- Automatic removal of recognized legacy metadata files only after successful
  database import. Failed imports, unknown files, backups, credentials and
  private Finder content are preserved.
- Settings → About → Check for updates; newer macOS releases are downloaded from
  this repository, cryptographically verified, installed and restarted in-app.
- Clean production identifiers, release logging defaults and About information.
- Windows retains its existing MSIX/Explorer integration and package-managed
  update path. This release does not ship a replacement Windows installer.

## Installation and security notices

The DMG is for manual installation. The `.app.tar.gz` and `.sig` assets are for
the in-app updater, not manual extraction. Older apps without the updater need
this first manual installation.

This build is ad-hoc signed, **not Apple Developer ID signed or notarized**.
macOS may require explicit approval to open it and may display warnings again
after an update. Updater signatures authenticate our release packages; they do
not replace Apple notarization. The app does not disable Gatekeeper or strip
quarantine attributes to suppress warnings.

The macOS download is for Apple silicon. Intel macOS and Windows binaries are
not included in this release.
